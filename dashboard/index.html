How it works

Game (browser)→Supabase bronze→ dbt silver: clean, deduplicate, classify mistakes→ dbt gold: star schema and marts→this page

A GitHub Actions run every night simulates the previous day's players, rebuilds and tests every model with dbt, and exports the gold marts to this static page. No database key reaches the browser.
