# Dashboard

Evidence.dev site built from the `gold` schema and published to GitHub Pages
after the nightly `dbt build`. Scaffolded in week 4 with `npx degit evidence-dev/template`.

Questions it answers:
- Which times tables and levels are hardest?
- Which error types are most common: off by one, reversed digits, wrong operation?
- How does response time change with level?
- Where in a session do players give up?
- Real vs simulated players, Danish vs English.
